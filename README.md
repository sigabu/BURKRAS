# БУРКРАС / BURKRAS

Демонстрационный сайт начинающей компании: алмазное бурение, резка, усиление проёмов и демонтаж в Красноярске. Новая айдентика, адаптивный интерфейс, калькулятор, описания услуг, FAQ и формы. Формы **не отправляют и не сохраняют** контакты, тарифы калькулятора **демонстрационные**.

- Сайт: https://sigabu.github.io/BURKRAS/
- Репозиторий: https://github.com/sigabu/BURKRAS

## Локальный запуск

Нужен Node.js 22 или новее. Установка пакетов и сборка не нужны.

```sh
npm run dev
```

Откройте http://127.0.0.1:4173/BURKRAS/.

```sh
npm test
npm run check
```

## Публикация

GitHub Actions проверяет проект и публикует только `site/` в Pages после push в `main`. Источник Pages — **GitHub Actions**. Все локальные ссылки относительные, поэтому сайт работает в `/BURKRAS/` и может переехать на отдельный домен.

## Что подготовлено

- Новая айдентика с круговым резом, крупный фотографический первый экран и услуги в виде открытого списка.
- Локальные кириллические Oswald и Onest, лицензии OFL в `site/assets/fonts/`. Лицензированные демонстрационные фотографии процессов и Красноярска в WebP, [атрибуция](site/credits.html). Запросов к внешним сервисам за шрифтами и фотографиями нет.
- Четыре услуги, калькулятор с диапазоном и индивидуальным расчётом усиления, формы с валидацией телефона и согласия.
- Контактные формы содержат единый API-адаптер, пометки `TODO(BACKEND)` и демо-режим, который не выполняет сетевые запросы.
- Диалоги, мобильное меню, клавиатурный фокус, reduced motion и объяснение обработки данных.
