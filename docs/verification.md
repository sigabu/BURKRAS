# Проверка демонстрации

23 ноября 2026 года, локальный Chrome через Playwright CLI.

- 11 тестов Node.js: минимальный заказ, влияние материала/размеров/количества, дробные размеры, индивидуальное усиление, некорректные значения, телефон и согласие, отсутствие сети в демо, HTTPS-адаптер и ошибки сервера.
- Статическая проверка: ресурсы, внутренние ссылки и якоря, синтаксис ES-модулей, обязательные пометки интеграции.
- Ширина страницы равна ширине окна на 320, 390, 768, 1024, 1440 и 1920 px: горизонтального скролла нет.
- Все SVG и локальные шрифты загрузились. В консоли браузера нет ошибок и предупреждений.
- Калькулятор: переход из описания услуги, индивидуальная оценка усиления, переключение на бурение/резку, сохранение параметров каждой услуги, дробная длина, блокировка запроса при нулевой толщине, перенос параметров в форму.
- Обе формы: некорректный телефон отклоняется; корректная демо-заявка показывает честное подтверждение; телефон и остальные поля очищаются. При завершении обеих форм зафиксировано **0 POST-запросов**, `localStorage.length = 0`, `sessionStorage.length = 0`.
- Диалоги удерживают фокус и закрываются по Escape, блокируют прокрутку фона.
- Мобильное меню открывается, закрывается по переходу; FAQ раскрывается.
- Просмотрены скриншоты desktop и mobile, исправлена прозрачность фактуры бетона. Поля на телефоне имеют размер шрифта 16 px для предотвращения автозума.

Скриншоты и временные результаты находятся в игнорируемом `output/playwright/`. Проверка подтверждает работу демонстрации, а не реального сервера: live API и БД не развёрнуты.

## Вторая версия дизайна

UI/UX Pro Max заменил предыдущий дизайн-скилл. Первая схема больше не служит визуальным ориентиром. Добавлены локальные Oswald / Onest и лицензированные WebP-фотографии с атрибуцией. Крупные строки услуг заменили сетку карточек; калькулятор, формы, FAQ и диалоги используют существующую логику.

Проверки второй версии: все 11 тестов и статическая проверка; визуальная проверка первой страницы и полного сайта; повторная проверка ширин 320–1920 px, меню, диалогов, расчёта и отправки демо-форм. Источники фото находятся в credits.html. Удаление маркировок не заменяет фотографии реальных объектов компании.

Синий и голубой подтверждены CSS и вычисленными стилями референса; документированы в `docs/ensib-palette.md`.
